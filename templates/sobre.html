Sobre o projeto

Entrega da {{ atividade }}: arquitetura em duas camadas na AWS.

Arquitetura

Navegador → http://IP_PUBLICO_APP:5000 → Flask (App) → IP_PRIVADO_DB:3306 → MySQL (DB)

Etapas

  1. Instâncias: app-khalil (Flask) e db-khalil (MySQL), Ubuntu, mesma VPC e mesmo par de chaves.
  2. Security Groups: App libera 22 e 5000; DB libera 22 e 3306, sendo a 3306 aceita só a partir do Security Group da App.
  3. MySQL: bind-address aberto para a rede, banco atividade4 e usuário próprio da aplicação, que só conecta do IP privado da App e só tem acesso a esse banco.
  4. Credenciais: no arquivo .env (fora do GitHub), carregado com load_dotenv().
  5. Rotas: /cadastro insere com consulta parametrizada; /listar mostra os registros.
  6. Execução: Gunicorn em 0.0.0.0:5000 como serviço do systemd.

Tecnologias

  • Python
  • Flask
  • PyMySQL
  • python-dotenv
  • MySQL
  • Gunicorn
  • AWS EC2
