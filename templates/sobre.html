Sobre o projeto

Entrega da {{ atividade }}: arquitetura em duas camadas com Docker.

Arquitetura

Navegador → http://IP_PUBLICO:5000 → container web (Flask) → db:3306 (rede interna) → container db (MySQL)

Etapas

  1. Containers: web (Flask) e db (MySQL 8), definidos no docker-compose.yml, na mesma rede interna rede-interna.
  2. Isolamento: só a porta 5000 do web é publicada. O MySQL não publica a 3306, então não fica exposto à internet; o Security Group libera só 22 e 5000.
  3. MySQL: o container cria o banco atividade4, o usuário da aplicação (não é root, só tem acesso a esse banco) e a tabela, a partir do db/schema.sql. Os dados ficam num volume.
  4. Credenciais: no arquivo .env (fora do GitHub e fora da imagem), carregado com load_dotenv().
  5. Rotas: /cadastro insere com consulta parametrizada; /listar mostra os registros.
  6. Execução: Gunicorn em 0.0.0.0:5000 dentro do container, com restart: always.

Tecnologias

  • Python
  • Flask
  • PyMySQL
  • python-dotenv
  • MySQL 8
  • Gunicorn
  • Docker
  • Docker Compose
  • AWS EC2
